# Language Routing

Resolve the visible interaction language from the user's newest direct instruction. Exclude attachments, quotations, pasted drafts, research excerpts, code, metadata, names, and action output from that decision.

Resolve story language separately: explicit instruction first, existing draft language for revisions second, interaction language otherwise. Localize UI headers, choices, plans, status messages, errors, and delivery notes.
