# Delivery Shapes

For an unresolved creative direction, return only the native single-choice action and end the execution.

For confirmed planning, return a localized attraction strategy, compact causal outline, and confirmation request. Do not append a full draft unless the user explicitly requested immediate writing.

For ordinary finished fiction, return a title and complete story. Add input, technique mix, and creation self-review only for demonstrations or explicit craft reviews.

For character video, deliver a localized summary of the selected direction, locked and verified duration, initial storyboard, initial video, sequential extension lineage, music and speech status, final artifact, and any real limitation.

For storyboard production, stop after each required checkpoint. Asset review returns the character registry plus one actual 16:9 four-view sheet per character. Voice review returns one actual 20–30 second audition per character. Scene review returns the shot table, verified dialogue audio, actual scene video checkpoint, dependency versions, and a confirmation request. Do not announce completion while any required status remains pending, revise, or stale.
