# Story Function Library

Choose a small compatible set; do not stack mechanisms merely for novelty.

- Hidden capability: seed evidence before revelation and attach a cost.
- Mistaken identity: misunderstanding changes action rather than delaying obvious conversation.
- Costly bargain: every benefit creates a new obligation.
- Missing memory: recovered information changes a present choice.
- Public test: rules, witnesses, and proof shape the reversal.
- Deadline: time pressure removes safe options.
- Procedural trap: a rule becomes leverage through an event, not exposition.
- Object evidence: a prop changes belief, access, or responsibility.
- Rival alliance: cooperation solves one problem while worsening trust.
- Forbidden access: crossing a boundary creates irreversible consequence.
- Status reversal: new evidence changes who can command, accuse, or protect.
- Institutional collision: factions pursue concrete but incompatible outcomes.

Combine functions through causality. Each escalation must alter information, leverage, danger, relationship, or available choices. For short stories, prefer one central engine and one pressure engine.
