# Research To Original Direction

Run research only when the user asks for current or source-backed information and a compatible action is connected. Record public facts separately from interpretation and avoid treating search summaries as verified facts without support.

Translate useful findings into general narrative functions, constraints, social incentives, visual contrasts, or conflict mechanisms. Build new characters, setting, causality, scenes, and language around them.

If research produces several viable creative directions, form exactly four distinct bundles and invoke the native selector. Do not return the bundle list in text. If research capability is missing, state the limitation rather than inventing results.
