# Feedback Learning

After user feedback, classify the cause before changing instructions: route choice, language handling, topic interaction, story planning, scene execution, media continuity, duration logic, audio recovery, or delivery.

Fix the immediate work at the smallest sufficient layer. Promote a new reusable rule only when it is supported by more than one situation or expresses a genuine invariant. Keep isolated preferences local to the current project.

When maintaining the package, add observable validation for a stable failure without duplicating the same rule across every file. Preserve confirmed behavior while repairing the failed branch.
