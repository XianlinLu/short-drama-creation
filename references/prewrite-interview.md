# Prewrite Decision Gate

When the user supplies only a broad theme or image, do not conduct a long generic interview. Infer four complete creative directions from available context and invoke the native single-choice card. Each direction should differ in emotional payoff, pressure relationship, conflict arena, escalation, and ending.

After selection, surface only missing information that materially changes the work. For story writing, present an attraction strategy and compact outline, then stop for confirmation unless the user asks to write directly. For character video, require the target duration before media generation.

The card requirements and failure behavior are defined in `references/interaction-and-topic-ui.md`.
