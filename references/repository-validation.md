# Repository Validation Entry

Validate configuration parsing, declared resource paths, supported text extensions, allowed filenames, per-document character limits, skill frontmatter, README naming, and the absence of stale declarations.

Behavioral tests must cover Chinese, English, and Japanese interaction; topic cards across image, idea, draft, reference, and research inputs; missing native UI; reachable and unreachable video durations; tail-only extension rejection; local zero-based prompts; original music; and one-chunk TTS audit failure.

Use `references/package-validation.md` as the authoritative checklist.
