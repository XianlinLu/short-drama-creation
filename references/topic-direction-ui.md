# Native Topic Direction Card

At every creative-direction choice point, invoke one native single-choice user-input action. Supply one localized question, exactly four mutually exclusive directions, the recommended direction first, concise option descriptions, and the native Other and submit controls.

This applies to all routes and inputs. End the execution after invoking the action. Do not repeat choices as Markdown, JSON, prose, tables, numbers, or simulated controls. If the native action is unavailable, stop without selecting for the user or starting downstream work.

The full action contract, language routing, retry limit, and preflight check are in `references/interaction-and-topic-ui.md`.
