# Story Example Fixture: Borrowed Weather

This is an acceptance fixture, not text for direct reuse.

In a city where residents rent artificial weather for private rooms, a maintenance worker discovers that one customer's recurring rain contains memories from a missing neighbor. The story should make the speculative rule visible through action, connect the worker's goal to a personal cost, and let each recovered fragment narrow available choices.

Expected craft: one speculative premise, one institutional constraint, concrete sensory evidence, dialogue under pressure, and a final decision that changes who owns the memories.

The result passes only if the premise develops through original characters, scenes, causality, language, and images.
